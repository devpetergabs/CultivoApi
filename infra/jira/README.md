# Jira — papel dentro do stack analítico

Nesta etapa, o Jira permanece como fonte de incidentes/trabalho para o projeto do DevLake.

## Regra que fica fixa

Não usar board administrativo, board pessoal ou board misto para alimentar incidente de DORA.

## Antes do primeiro sync real

- stack validado por `validate-observability.sh`
- `doctor-observability.sh` sem falha gritante
- boardId confirmado
- projeto piloto separado do board de gestão pessoal
