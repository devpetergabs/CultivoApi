# Tema: Finalização

## Escopo
Use esta pasta para perguntas sobre reta final do ciclo, maturação, leitura de tricomas, janela de colheita, flush e cautela de manejo tardio.

## Exemplos de perguntas
- `tricomas leitosos com alguns âmbar, já colho?`
- `o que muda da flora avançada para finalização?`
- `posso pulverizar agora na finalização?`
- `flush agora faz sentido?`

## Prioridade de uso
1. fontes desta pasta
2. `the-bible.pdf`
3. `extracao/` quando houver objetivo explícito de extração

## Resultado esperado
A resposta deve conectar:
- estágio final da planta
- leitura de maturação
- risco de intervenção tardia
- implicação prática de colheita ou de cautela operacional
