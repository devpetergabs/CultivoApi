# Tema: Extração

## Escopo
Use esta pasta para perguntas cujo eixo principal seja o destino pós-colheita e a relação entre ponto de corte, resina, terpenos e método de extração.

## Exemplos de perguntas
- `quero colher pensando em live resin`
- `para hash a janela muda?`
- `extração muda a leitura do ponto de colheita?`
- `como preservar melhor a fração aromática para extração?`

## Prioridade de uso
1. fontes desta pasta
2. `finalizacao/` quando a pergunta cruzar maturação e timing
3. `the-bible.pdf` como base fisiológica geral

## Resultado esperado
A resposta deve conectar:
- objetivo de extração
- leitura de maturação/resina
- trade-off entre rendimento, perfil desejado e momento de corte
